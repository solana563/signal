Your own library OPTIONAL

Plug in a catalogue you own or are licensed to use (your own server, a Jellyfin/Plex bridge, public-domain collections). SIGNAL adds it as a “My Library” row and plays the links through the built-in player (HLS .m3u8 or direct .mp4/.webm).

Expected JSON format 
[
  { "title": "Big Buck Bunny",
    "url": "https://…/video.m3u8",
    "poster": "https://…/poster.jpg",
    "year": "2008" }
]

A bare array, or an object like {"items":[…]}. Only title and url are required. The server must allow cross-origin requests (CORS).
